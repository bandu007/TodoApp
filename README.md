#Title: Todo App Version 1 
#Description: This is merely the backend where I have done the following as expected 
1.Setup Project 
2.Configure the APIs and the respective functions.
3.Use Controller services and routing structure. 
4.Error handling and validation
5.Testing via thunder client 
6. Configuration of Mongo DB connecting to it. 

Pre-requisites to run this project
*Visual Studio Code software on a windows machine.
*For back end you would need to install the node js, express modules nodemon, mongoose and dotenv modules . 
*Finally a MongoDB connection is to be established. The username and password in a .env file

Instructions to run this Project:

1. Download the complete Project
2. Open up a visual studio code software on your computer
3. Open the Project folder.
4. Open the integrated terminal from the Project folder by right clicking on it and getting the option.
5. You will get the terminal, in the terminal write npm start and press enter, you must get 2 messages on the console, DB Connected and Server is up.
6. Use the thunderclient and start sending the messages to the routes as defined in Todo-routes.js and the main index.js. Use the appropriate JSON formats to send the request in the body section to avoid errors
